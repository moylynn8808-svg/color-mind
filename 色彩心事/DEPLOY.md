# 色彩心事 - 部署指南

## 方式一：Vercel 部署（推荐）

### 步骤：
1. 访问 https://vercel.com
2. 点击 "Add New Project"
3. 选择 "Import Git Repository" 或直接将代码文件夹拖拽上传
4. 项目会自动部署，获得一个类似 `https://your-project.vercel.app` 的链接
5. 将链接分享给朋友即可

### 优点：
- 免费、快速、全球 CDN 加速
- 自动 HTTPS
- 每次代码更新自动重新部署

---

## 方式二：GitHub Pages（免费）

### 步骤：
1. 在 GitHub 创建新仓库（如 `color-mind`）
2. 上传代码到仓库
3. 进入 Settings → Pages
4. Source 选择 "Deploy from a branch"，Branch 选择 "main"
5. 获得链接如 `https://yourname.github.io/color-mind`

---

## 方式三：腾讯云/阿里云静态网站托管

### 步骤：
1. 购买域名（可选）
2. 进入对象存储 COS / OSS
3. 开启静态网站托管
4. 上传代码文件
5. 绑定自定义域名（可选）

---

## 方式四：直接发送文件（最简单）

直接将整个 `色彩心事` 文件夹压缩发给朋友：
- 朋友解压后双击 `index.html` 即可在浏览器打开
- ⚠️ 注意：历史记录功能需要服务器环境，本地打开可能无法保存

---

## 方式五：微信开发者工具（转成微信小程序）

如果想发布为微信小程序：
1. 下载微信开发者工具
2. 需要适配代码（HTML→WXML，CSS→WXSS）
3. 注册小程序账号并上传

---

## 快速分享建议

**最快方式：**
1. 将整个 `色彩心事` 文件夹压缩为 `色彩心事.zip`
2. 通过微信/QQ/邮件发给朋友
3. 朋友解压后用浏览器打开 `index.html`

**最专业方式：**
1. 部署到 Vercel
2. 获得专属链接
3. 生成二维码分享
